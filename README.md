# PerceptTwin

This work tackles the problem of reconstructing real-world scenes into simulation from an input semantic scene map generated by methods such as [ConceptGraphs](https://concept-graphs.github.io/).

This is research code, and we offer no guarantees regarding side effects or destructive changes to your local files or machine. Reading the code, you will notice that it builds directly upon the [Holodeck](https://github.com/allenai/Holodeck) codebase and extends it to consume [ConceptGraphs](https://concept-graphs.github.io/) as input. We also implement object asset generation from images using the [TRELLIS](https://github.com/microsoft/TRELLIS) codebase. The TRELLIS generation is implemented using a thin webserver API; by opening a port-forwarding SSH tunnel, you can use the PerceptTwin code locally and place the TRELLIS model (requires a good, recent GPU) on a remote compute cluster. The webserver API is implemented in our fork of TRELLIS, at [velythyl/TRELLIS](https://github.com/Velythyl/TRELLIS).

Accepted at ICRA 2026.

[https://percept-twin.github.io/](https://percept-twin.github.io/)


# Installation

Install `Holodeck`, following their instructions.
Then,

```bash
python3.10 -m venv venv
pip3 install -r requirements.txt
pip3 install --extra-index-url https://ai2thor-pypi.allenai.org ai2thor==0+8524eadda94df0ab2dbb2ef5a577e4d37c712897
pip3 install "jax[cuda12]" # or if on Apple Silicon  pip3 install jax-metal==0.1.1 jax==0.5.0 jaxlib==0.5.0
pip3 install open3d # or if on Apple Silicon: open3d wheels are a bit wonky, try:  wget https://github.com/isl-org/Open3D/releases/download/v0.17.0/open3d-0.17.0-1fix6008-cp310-cp310-macosx_12_0_arm64.whl && pip3 install open3d-0.17.0-1fix6008-cp310-cp310-macosx_12_0_arm64.whl && brew install libomp
```
